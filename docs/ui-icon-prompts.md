# UI icon generation prompts

Version 1.0.23 edits the seven existing UI icon assets using the built-in image-generation tool. Each blue tile is an edit target; the new black overview tile is the common material reference. Prompts below are the exact prompts used.

The original output PNGs are in `desktop/assets/ui-icons/`. Uniform CSS scaling, rounded clipping and shadows integrate them into the app. The native API Key eye button uses the same black material and light glyph; primary and secondary controls share rounded corners and raised/pressed states. The approved application logo artwork is unchanged.

## overview

```text
Use case: precise-object-edit.
Asset: one production desktop UI icon.
Input image 1 is the EXISTING ICON TO EDIT. Preserve its exact white symbol silhouette, centered size, spacing, orientation and rounded-square tile outline. No redesign of the pictogram.
Change the blue-violet tile to deep neutral BLACK, with richer but restrained three-dimensional depth. Palette strictly achromatic: obsidian black #08090a lower surface, charcoal #232427 upper-left soft reflected highlight; never blue or purple or light gray overall. Rounded squircle tile viewed straight on, no perspective. A fine soft silver rim along the top-left bevel, a visibly thicker dark lower edge, a gentle short downward contact shadow. White symbol is subtly raised porcelain with delicately rounded edge highlights and a short soft dark contact shadow immediately beneath it. Keep the white face bright ivory, crisp and readable at 28px. Beautiful modern satin material, no glitter, no noisy texture, no extruded sidewalls, no large outer glow. Depth moderately more noticeable than input but professional and clean.
Tile same placement as input, centered with 7% transparent margin on each side; actually transparent pixels outside tile, no checkerboard or decorative particles. One icon, no text, no branding, no extra shapes.
```
